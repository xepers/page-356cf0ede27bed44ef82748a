客户端选择与官网下载指引

Anti免流的核心使用方式是「机场订阅 + 标准客户端」。请优先使用各系统社区广泛维护的客户端，在应用商店或项目发布页获取，再粘贴你的订阅链接。本页强调选择顺序，而不是捆绑来路不明的安装器。

选择原则

  1. 先确定系统：桌面优先 Clash 系或 v2rayN，移动端优先 Meta / Shadowrocket / Stash。
  2. 确认协议兼容：订阅一般同时提供 Clash 与通用 URI，按客户端类型导入。
  3. 只从官方渠道下载加速器本体，再用 Anti免流 账户内的订阅更新节点。
  4. 导入后测延迟，游戏与会议走专线组，浏览走负载均衡组。

若系统已预装其他代理，先关闭系统 VPN 或冲突插件，避免双层隧道。

分端下载对照

Windows：Clash Verge / Mihomo、v2rayN。导入 Clash 配置或订阅 URL。

macOS：ClashX Meta、Surge。适合规则分流与网卡增强。

Android：Clash Meta for Android、类似兼容面板。注意省电策略勿杀掉后台。

iOS：Shadowrocket、Stash、Quantumult X（需具备对应获取条件）。

路由器 / Linux：OpenWrt 上的 Mihomo、命令行订阅转换后常驻。

操作说明

  1. 在套餐区确定档位：流量、设备数、是否需要 IPLC 与优先工单。
  2. 完成账户开通后，在控制台复制订阅链接（Clash 与通用格式择一即可）。
  3. 打开「客户端选择」对应软件，使用官方下载来源安装。
  4. 在订阅/配置页粘贴链接，执行更新，等待节点列表出现。
  5. 选延迟较低且用途匹配的节点连接；流媒体走解锁组，游戏走专线组。
  6. 若无法访问：检查系统时间、重复代理、以及套餐流量是否用尽。

连接后建议检查

  • DNS 与漏泄：客户端开启防泄漏或 Fake-IP 时，避免再套一层浏览器插件。
  • 设备计数：同一账号在多台终端同时在线会占用额度。
  • 更新节奏：节点变更后先更新订阅再切换，减少旧配置报错。

线路与加速策略

常见问题

Anti免流（Anti）是什么？和普通 VPN、机场订阅有何关系？

Anti免流是提供跨境网络加速的机场订阅服务，配合 Clash、v2rayN、Shadowrocket 等客户端使用。它属于订阅制梯子/加速器，而不是手机运营商免流套餐。你在官网选择套餐、下载客户端并导入订阅后即可按节点访问，请仅用于合法合规场景。

如何从官网完成客户端下载且避免装错软件？

先在本页「客户端选择与官网下载指引」确认系统对应的常用工具名称，再到该工具的官方项目页或应用商店下载。Anti免流提供订阅与节点，不把来路不明的加速器安装包作为唯一通道。装好后只粘贴账户内订阅链接。

订阅链接怎样导入？连不上时先看哪几步？

复制控制台订阅地址，在客户端的订阅或配置管理中粘贴并更新。成功后刷新节点再连接。若失败，依次检查：链接是否完整、客户端是否支持该配置格式、本地时间是否准确、是否与系统 VPN 冲突、当月流量是否耗尽。

三个套餐的设备数和流量如何理解？

基础版每月 100GB、3 台同时在线；旗舰版 300GB、5 台，并包含全节点原生流媒体解锁与 IPLC 游戏优化；团队版 1000GB、20 台，带 VIP 高带宽与定制路由沟通。同时在线以实际会话为准，平板、手机、电脑通常分别计数。

旗舰版的 IPLC 游戏加速适合哪些人？

需要更稳回程、更低抖动的对战、国际服登录和实时语音用户。普通网页浏览不必强上专线。若你同时看重解锁完整性与工单响应，旗舰版比基础版更合适；多人共享再考虑团队版。

流量用尽、需要对公或定制路由怎么处理？

可在周期内升级更高档位，或等待流量重置。团队版提供专属客户经理，便于对公沟通与企业定制路由。工单优先级以套餐条款为准，旗舰版标注 7x24 优先支持。
